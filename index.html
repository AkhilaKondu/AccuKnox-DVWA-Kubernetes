Attack Demonstrations

Three application attack surfaces were demonstrated in the local DVWA environment.

01. SQL Injection

Demonstrates how unsafe SQL query construction can expose unintended database records.

Mitigation: Use parameterized queries and least-privilege database accounts.

02. Reflected XSS

Demonstrates how untrusted input reflected in a response can execute JavaScript in a browser.

Mitigation: Use context-aware output encoding and appropriate input validation.

03. Command Injection

Demonstrates how unsafe operating-system command construction can execute unintended commands.

Mitigation: Avoid shell commands where possible, use safe APIs, and validate input.
