DVWA

An intentionally vulnerable application for authorized security learning.

Attack Demonstrations

01. SQL Injection

Demonstrates how unsafe SQL query construction can expose unintended database records.

Mitigation: Parameterized queries and least-privilege database accounts.

02. Reflected XSS

Demonstrates browser execution of untrusted input reflected in a response.

Mitigation: Context-aware output encoding and input validation.

03. Command Injection

Demonstrates how unsafe operating-system command construction can execute unintended commands.

Mitigation: Avoid shell commands where possible; use safe APIs and strict input validation.
